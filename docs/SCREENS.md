# الشاشات في M-SAL2.0

> نتيجة جلسة التخطيط 4 (2026-10-31). مبنية على شاشات M-SAL القديم (`index.html`)، و[BUSINESS_RULES.md](BUSINESS_RULES.md)، و[API.md](API.md).
> **المبدأ:** كل شاشة **تطابق** القديمة في الشكل والسلوك. الجديد فقط: الدخول، والإدارة، وتعليمات التثبيت، وقفل Face ID.

> ⚠️ **بعد التصميم الجديد (فرع `redesign`، 2026-11-06):** الشكل والترتيب تغيّرا حسب [DESIGN.md](DESIGN.md)، وهو المرجع لهما حيث يختلف عن هذا الملف. أهم الفروق:
> - **هوية واحدة:** الزجاج الأزرق لكل الشاشات (نمط الورق انتهى، والقسم 8 هنا تاريخي)، مع فاتح وداكن واختيار يدوي.
> - **الرأس:** اسم الشخص وقائمته (بدل القائمة المنسدلة وزرَّي ✎ ×)، و"محفوظ" في الميزانية أو الدورة `‹ … ›` في المصاريف، ومفتاح القسمين. الشهر والمتبقي انتقلا لبطاقة الميزانية.
> - **S-10:** بطاقة "المتبقي" فوق (الشهر، والراتب، و⋯ للأدوات)، والمجموعات تنطوي، و"+ شخص" في قائمة الشخص.
> - **S-20:** بلا شريط الدورة ولا مربعَي "المصروف" و"المخصَّص" (صارا سطراً في بطاقة الحساب)، وتصفح الأيام (R-ENT-16)، و"وصل الراتب" تحت آخر المصاريف.
> - **S-21:** صفوف بالسحب (حذف ونسخ) بدل الأزرار، والفئات خلف زر فلتر، و**"كرّر" حُذف**.
> - **SH-01:** اختصارات بضغطة (R-ENT-14)، ولوحة أرقام بدل كيبورد الآيفون، والفئات صف واحد بالاستخدام (R-ENT-15)، والتاريخ شريحة صغيرة.
> - **SH-08:** مجموعات مثل الآيفون، و"المظهر" أولاً (مع صور البطاقات).
> - **الإيصالان:** بطاقة زجاج داكنة. **S-01، S-02، S-03:** المحفظة، و6 خانات للرمز، وخطوات مرسومة.
> - **جديد:** صورة خلف البطاقتين الكبيرتين (على الجهاز فقط)، والمحفظة الطايرة، وحركة الحفظ والعدّ، والانزلاق بين القسمين.

> **رسائل البنك (المرحلة 11، [BANK-SMS.md](BANK-SMS.md)، 2026-11-07):**
> - **S-20:** شريط "N بانتظار المراجعة" **فوق بطاقة الحساب** إذا `pendingCount > 0` (B-04)، يفتح:
> - **S-23 `/expenses/pending` "بانتظار المراجعة":** بطاقات (B-18): رمز الفئة، والجهة، والوقت، والمبلغ، وشريحة الفئة (تُغيَّر بضغطة، و"تذكّر هذه الجهة" إذا تغيّرت)، والوصف مع اقتراحاته، و"نص الرسالة"، و"اعتماد" و"تجاهل". بعد آخر بطاقة ترجع للرئيسية.
> - **SH-08 ← SH-14 "رسائل البنك":** أربع مجموعات (B-19): الحساب، والربط مع الآيفون (الرمز مرة واحدة، وآخر استخدام، وإلغاء، والخطوات)، والكلمات حسب الفئة، و"اختر الفئة كل مرة".
> - **S-04 `/bank-sms/setup` "رسائل البنك من الآيفون":** خطوات الاختصار مرسومة مثل صفحة التثبيت (D-31)، مع نسخ العنوان والرمز.
> - كلها حسب صلاحية `SRV-011`.

## 1. المبادئ

| المبدأ | التفاصيل |
|---|---|
| **الجوال أولاً** | مصمم لعرض 375px (آيفون)، ويعمل على الشاشات الأكبر |
| **عربي RTL** | `lang="ar" dir="rtl"`، والأرقام لاتينية دائماً (R-GEN-05) |
| **قسمان بهويتين** | **الميزانية**: نمط الورق (كريمي، وأخضر، ونحاسي). **المصاريف**: نمط الزجاج (أزرق). كما في القديم تماماً |
| **فاتح وداكن** | تلقائياً حسب إعداد الجوال |
| **أهداف اللمس** | 44px على الأقل لكل زر |
| **حواف الآيفون** | احترام `safe-area-inset` (النوتش والشريط السفلي) |
| **الحركة** | انزلاق النوافذ وطي الأقسام كما في القديم، وتتوقف إذا فعّل المستخدم "تقليل الحركة" |
| **لا `prompt()` ولا `confirm()`** | القديم يستخدم نوافذ المتصفح الافتراضية للأسماء والتأكيد. الجديد يستبدلها بمكونات مطابقة للتصميم، **بنفس النصوص ونفس الخطوات** |

## 2. خريطة التنقل

```
                     ┌──────────────┐
  أول فتح من Safari ─→│ S-02 التثبيت │ (إذا لم يُثبَّت على الشاشة الرئيسية)
                     └──────────────┘
                     ┌──────────────┐
  غير مسجّل ─────────→│ S-01 الدخول  │──→ رمز الإيميل ──→ /
                     └──────────────┘
                     ┌──────────────┐
  رجوع بعد غياب ─────→│ S-03 القفل   │ (إذا Face ID مفعّل)
                     └──────────────┘

  /  ──→ آخر قسم استُخدم (يُحفظ في الجهاز، كما في القديم)
   │
   ├── /budget ─────────────── S-10 الميزانية الشهرية
   │
   ├── /expenses/home ──────── S-20 الرئيسية      ┐
   ├── /expenses/entries ───── S-21 المصاريف      ├─ الشريط السفلي + زر الإضافة (+)
   ├── /expenses/stats ─────── S-22 الإحصاءات     ┘   "المزيد" يفتح نافذة SH-03
   │
   └── /admin ──────────────── S-30 الإدارة (فقط مع صلاحية SRV-009)
```

| المسار | الشاشة | الحماية | المعاملات (query) |
|---|---|---|---|
| `/login` | S-01 الدخول | للزوار فقط | |
| `/install` | S-02 التثبيت | بدون | |
| `/budget` | S-10 الميزانية | دخول + SRV-002 | |

## 3. الشاشات

> **الكود** = كود الخدمة. **API** = الطلبات من [API.md](API.md). **المصدر** = الدالة في `index.html` القديم.

### S-01: الدخول (جديدة)

| | |
|---|---|
| **الهدف** | الدخول برمز الإيميل (API.md 2.1) |
| **الخطوة 1** | حقل الإيميل + زر "أرسل الرمز" |
| **الخطوة 2** | 6 خانات للرمز (تدعم اللصق والتعبئة التلقائية من iOS)، وزر "إعادة الإرسال" بعد 60 ثانية، ورابط "تغيير الإيميل" |
| **بعد النجاح** | `GET /me` ثم `/` |
| **الأخطاء** | إيميل غير مدعو ← "هذا البريد غير مدعو لاستخدام التطبيق." (`SRV-000-E001`). رمز خاطئ ← "الرمز غير صحيح." |
| **الشكل** | نمط الورق، مع شعار M-SAL واسم "ميزانية الشهر" |

### S-02: تعليمات التثبيت (جديدة)

| | |
|---|---|
| **متى تظهر** | فتح التطبيق من **Safari على الآيفون** وهو **غير مثبت** على الشاشة الرئيسية |
| **المحتوى** | 3 خطوات مصوّرة: زر المشاركة ⬆️ ← "إضافة إلى الشاشة الرئيسية" ← "إضافة" |
| **تخطٍّ** | زر "متابعة في المتصفح" يكمل للدخول بدون تثبيت |
| **على أجهزة أخرى** | لا تظهر تلقائياً، ومتاحة من الإعدادات |

### S-03: قفل Face ID (جديدة)

| | |
|---|---|
| **متى** | عند فتح التطبيق، أو الرجوع له بعد **5 دقائق** في الخلفية، **إذا فعّله المستخدم** من الإعدادات |
| **المحتوى** | شعار + زر "افتح بـ Face ID"، والمحتوى خلفه مخفي |
| **التقنية** | passkey عن طريق WebAuthn على الجهاز نفسه |
| **ملاحظة صريحة** | هذا **قفل خصوصية** يمنع من يمسك جوالك من رؤية ميزانيتك، وليس بديلاً عن تسجيل الدخول. الحماية الحقيقية هي JWT والسيرفر |
| **فشل Face ID** | زر "تسجيل الخروج والدخول بالإيميل" |

### الرأس المشترك (Header)

*المصدر: `topHeader`، و`renderProfileSelect`، و`showTab`*

| العنصر | السلوك |
|---|---|
| **قائمة "الأشخاص"** | الميزانيات + "＋ شخص جديد…"، مع زر ✎ (إعادة تسمية) و× (حذف) |
| **مؤشر الحفظ** | "محفوظ ✓" بعد كل حفظ ناجح، و"لم يُحفظ" عند الفشل (API.md 5) |
| **التبويبان** | "الميزانية" و"المصاريف"، ويُتذكَّر آخر تبويب على الجهاز |
| **في الميزانية فقط** | اسم الشهر (قابل للتعديل)، و"M-SAL"، و"المتبقي" بخط كبير |
| **عند التمرير** | يصغر الرأس |

| **في "بدون دورة"** | المجموع، وزر "إضافة دورة سابقة" |
| **بدون دورات** | "ابدأ دورتك الأولى" مع الشرح |

### S-21: المصاريف، القائمة

*الكود: SRV-001 · المصدر: `renderEntriesView`، و`renderDayCards` · القواعد: R-ENT-08، وR-ENT-10، وR-ENT-11*

| العنصر | السلوك |
|---|---|
| **البحث** | "ابحث بالاسم أو الفئة"، والنتائج تتحدث أثناء الكتابة (بتأخير 300ms ثم طلب للسيرفر) |
| **شرائح الفئات** | "الكل" + الفئات (المخفية تظهر فقط إذا مستخدمة في هذه الدورة)، وضغطة ثانية تلغي التصفية |
| **"كرّر"** | "كرر: قهوة — 18 د.إ"، ينسخ آخر مصروف بتاريخ اليوم (R-ENT-07، R-ENT-08) |
| **بطاقات الأيام** | لكل يوم: العنوان ("اليوم"، "أمس"...)، ومجموع المصاريف، و"+" للدخل |
| **صف المصروف** | الرمز، والوصف، والمبلغ، والفئة (إذا الوصف مختلف عنها)، وأزرار ✎ ⧉ 🗑 |
| **بدون نتائج** | "لا توجد نتائج مطابقة." أو "لا توجد مصاريف في هذه الدورة بعد. اضغط + لإضافة مصروف." |
| **البيانات** | `GET /accounts/{id}/entries?cycle=…&q=…&categoryId=…`، و`GET …/last-expense` |

### S-22: الإحصاءات

*الكود: SRV-006 · المصدر: `renderStatsView` · القواعد: R-STA-01 إلى 06*

| البطاقة | المحتوى |
|---|---|
| **إجمالي المصروف** | المبلغ، والمتوسط اليومي، وعدد المصاريف، والدخل الإضافي (إذا وُجد) |
| **حسب الفئة** | حلقة (donut) بالإجمالي في الوسط، وقائمة بالنسب |
| **آخر 7 أيام** | أعمدة، واليوم بلون أوضح |
| **اتجاه آخر 6 دورات** | منحنى ناعم مع تظليل (للدورات فقط) |
| **أكبر التغيّرات** | حتى 5، بوسوم "جديد" و"ارتفاع" و"انخفاض" (للدورات فقط) |
| **الاستخدام حسب الفئة** | مبلغ وشريط لكل فئة. **الضغط على الفئة** يفتح مصاريفها مجمّعة حسب اليوم، الأحدث أولاً، فئة وحدة مفتوحة، للعرض فقط (`DESIGN.md` D-39) |
| **"شارك ملخصك"** | يفتح الإيصال |

- **الرسوم بـ SVG مكتوب يدوياً بدون مكتبات**، كما في القديم: أخف وأسرع، وشكله مطابق.
- **البيانات:** `GET /accounts/{id}/stats?cycle=…`، ومصاريف الفئة المفتوحة `GET /accounts/{id}/entries?cycle=…&categoryId=…` (عند فتحها أول مرة).

### S-30: الإدارة (جديدة)

*الكود: SRV-009 · ADMIN فقط*

| التبويب | المحتوى | API |
|---|---|---|
| **المستخدمون** | الإيميل، والحالة، والأدوار، مع تفعيل وإيقاف | `GET/PATCH /admin/users` |
| **الدعوات** | دعوة جديدة (إيميل)، والقائمة بحالاتها، وإلغاء | `/admin/invitations` |
| **الخدمات** | SRV-000 إلى SRV-009 مع مفتاح تفعيل وإيقاف | `/admin/services` |
| **سجل النشاط** | تصفية بالمستخدم والخدمة والتاريخ، مع ترقيم صفحات | `GET /admin/audit-log` |

- **الوصول:** من نافذة "المزيد" (SH-03) ← "الإدارة"، ويظهر فقط مع صلاحية SRV-009.
- **التصميم:** نمط الورق، وبسيط. هذه شاشة إدارية وليست للاستخدام اليومي.

## 4. النوافذ المنزلقة (Sheets)

تنزلق من الأسفل، وتُغلق بالسحب للأسفل أو بالضغط خارجها، كما في القديم (`openSheet`، و`enableSheetDrag`).

| # | النافذة | تُفتح من | المحتوى والسلوك | API | المصدر |

### 4.1 SH-01: نافذة المصروف بالتفصيل

*المصدر: `openEntrySheet` · القواعد: R-ENT-01 إلى 05، وR-ENT-12*

```
┌─────────────────────────────────┐
│ ─────                           │  ← مقبض السحب
│ مصروف جديد                      │
│ [ مصروف | دخل ]                 │
│                                 │
│           46.25 د.إ             │  ← المبلغ في الوسط، يكبر مع الكتابة
│                                 │
│ التصنيف                         │
│ 🍔 🛒 ⛽ 🧾 ⚡ 💧 📱 🏠 ...       │  ← الشبكة، تُطوى بعد الاختيار إلى:
│ [🍔 أكل ومطاعم        تغيير]    │
│                                 │
│ الوصف                           │  ← يظهر بعد اختيار الفئة
│ [ غدا                        ]  │
│ [ريوق] [غدا] [عشا]              │  ← الاقتراحات
│                                 │
│ التاريخ                         │
│ [اليوم] [أمس] [تاريخ آخر]       │
│ التاريخ: اليوم · ضمن الدورة: 1 نوفمبر ← الآن │
│                                 │
│ خيارات أخرى ‹                   │  ← الحساب (فقط مع أكثر من حساب)
│ ┌─────────── حفظ ────────────┐  │  ← مثبت في الأسفل
└─────────────────────────────────┘
```

**سلوكيات يجب الحفاظ عليها بالضبط:**
1. **لوحة المفاتيح تفتح مع انزلاق النافذة** وليس بعدها. القديم يستخدم حقلاً مخفياً (`kbProxy`، و`primeKeyboard`) يأخذ التركيز داخل نفس الضغطة، ثم ينقله لحقل المبلغ. **iOS لا يفتح لوحة المفاتيح إلا داخل ضغطة المستخدم**، فهذه الحيلة ضرورية.
2. **الأرقام العربية تتحول لاتينية أثناء الكتابة** في حقل المبلغ.
3. **Enter في المبلغ:** ينتقل للوصف إذا الفئة مختارة. **Enter في الوصف:** يحفظ.
4. **بعد اختيار الفئة:** تُطوى الشبكة إلى صف واحد، ويظهر الوصف، وينتقل التركيز له.
5. **زر الحفظ** يبدو معطلاً حتى تكتمل البيانات، لكنه يستجيب ويعرض السبب. الوصف الفارغ يهتز.
6. **التاريخ ليس اليوم** ← الملاحظة بلون التنبيه.
7. **بعد الحفظ:** رسالة "أُضيف: 46.25 د.إ"، وينتقل العرض لدورة المصروف.
8. **عند تعديل مصروف بفئة مخفية**، تظهر الفئة في الشبكة.

### التذكير اليومي يحتاج إضافة صغيرة للسيرفر

الإشعارات على الآيفون تُرسل **من السيرفر** (Web Push)، فتحتاج:
- **جدول جديد** `push_subscriptions`، وعمود `daily_reminder_time` في `app_users` (ملف Flyway `V8`، انظر [DATABASE.md](DATABASE.md) القسم 7).
- **طلبات جديدة** تحت SRV-000 (انظر [API.md](API.md)).
- **مهمة مجدولة** في Spring Boot (`@Scheduled`) ترسل التذكير في وقته **فقط إذا لم يسجّل المستخدم أي مصروف اليوم**.
- **مجاني:** Web Push لا يحتاج خدمة مدفوعة.
- **التوقيت:** في مرحلة التنفيذ 7 (ميزات PWA)، وليس قبل.
